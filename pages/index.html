DHIS2 Helm charts

The Helm chart repository for deploying DHIS2 on Kubernetes.

Add the repository

helm repo add dhis2 https://dhis2-sre.github.io/dhis2-core-chart
helm repo update
helm search repo dhis2

Install a chart

helm install my-release dhis2/dhis2 --version <version>
